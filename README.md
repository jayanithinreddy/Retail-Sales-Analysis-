
# Retail Sales Analysis

## Project Overview
This project analyzes retail sales data using Excel, SQL, and Power BI to understand sales performance, profitability, customer behavior, and business trends.

## Tools Used
- Excel – Data preparation and analysis
- MySQL – Data querying and analysis
- Power BI – Interactive dashboard and visualization

## Project Files
- `retail_sales_analyst_project.csv` – Retail sales dataset
- `retail_sales.sql` – SQL queries used for analysis
- `retail dashboard.pbix` – Power BI dashboard file

## Key Analysis Areas
- Total Revenue
- Total Profit
- Total Orders
- Average Order Value
- Sales by Category
- Sales by City
- Sales by Region
- Payment Mode Analysis

## Project Objective
The objective of this project is to analyze retail sales data and present meaningful business insights through SQL queries and an interactive Power BI dashboard.
